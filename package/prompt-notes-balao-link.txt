Prompt para o Claude Code, aberto no diretório package/. Independente de outros prompts.

Pré-requisito: o dashboard.html já tem a aba Notes (procure por `.notes-body` e `function renderNoteEditor`). Se não tiver, pare e avise que é preciso aplicar antes o prompt-notes.txt; não crie a aba Notes por conta própria.

---

Na aba Notes do dashboard (dashboard.html), clicar num link dentro do editor deve mostrar um balão com ações, no estilo do Google Docs. Hoje o corpo da nota é contenteditable: um clique simples só põe o cursor no link, e só ⌘/Ctrl+clique abre. Por isso os links parecem não funcionar.

Decisões de produto (não mudar):
- Clique simples num link do editor (.notes-body) mostra um balão logo abaixo do link, alinhado à esquerda dele, sem passar da borda direita do editor. Conteúdo do balão: a URL (cortada com reticências se for longa; o tooltip mostra a URL completa), depois os botões "Abrir ↗" (abre em nova aba, em laranja/accent), "Editar" e "Remover".
- Editar: prompt com a URL atual. Cancelar ou deixar vazio não muda nada. URL sem esquema (http/https/mailto) ganha "https://". Se o texto do link era igual à URL antiga, o texto passa a ser a nova URL; senão, o texto fica como está. Grava a nota e reabre o balão com a URL nova.
- Remover: tira o link e mantém o texto (o <a> é trocado pelos filhos dele). Grava a nota.
- ⌘/Ctrl+clique continua abrindo o link direto, sem balão.
- O balão some com: clique fora de um link dentro do corpo, Esc, digitação, rolagem do corpo e perda de foco do corpo (clicar fora do editor). Clicar nos botões do balão não tira o foco do texto.
- Só um balão por vez. Ele vive dentro do .notes-editor, então trocar de nota (que reconstrói o editor) o remove.
- Os links não ganham mais o atributo `title` "⌘+clique para abrir" (que era gravado no notes.json). O título antigo continua nas notas já salvas e é removido do link quando ele é editado pelo balão.
- Cards da coluna e modo painel não mudam: lá os links já abrem com clique simples.

por exatamente:

```js
      // Clique num link mostra o balão (Abrir · Editar · Remover); ⌘/Ctrl+clique abre direto em nova aba
      let bubble = null;
      const hideLinkBubble = () => { if (bubble) { bubble.remove(); bubble = null; } };
      function showLinkBubble(a) {
        hideLinkBubble();
        bubble = document.createElement('div');
        bubble.className = 'note-link-bubble';
        bubble.innerHTML = `<span class="url"></span><button class="open">Abrir ↗</button><button class="edit">Editar</button><button class="unlink">Remover</button>`;
        bubble.querySelector('.url').textContent = a.href;
        bubble.querySelector('.url').title = a.href;
        bubble.addEventListener('mousedown', e => e.preventDefault()); // não tira o foco do texto
        bubble.querySelector('.open').addEventListener('click', () => { window.open(a.href, '_blank', 'noopener'); hideLinkBubble(); });
        bubble.querySelector('.edit').addEventListener('click', () => {
          const old = a.getAttribute('href');
          let url = prompt('URL do link:', old);
          if (url === null) return;
          url = url.trim();
          if (!url) return;
          if (!/^(https?:|mailto:)/i.test(url)) url = 'https://' + url;
          if (a.textContent === old) a.textContent = url; // link que mostra a própria URL acompanha a edição
          a.setAttribute('href', url);
          a.removeAttribute('title');
          syncBody();
          showLinkBubble(a);
        });
        bubble.querySelector('.unlink').addEventListener('click', () => {
          a.replaceWith(...a.childNodes);
          body.normalize();
          syncBody();
          hideLinkBubble();
        });
        notesEditor.appendChild(bubble);
        // Logo abaixo do link, sem passar da borda direita do editor
        const box = notesEditor.getBoundingClientRect(), r = a.getBoundingClientRect();
        bubble.style.top = (r.bottom - box.top + 4) + 'px';
        bubble.style.left = Math.max(8, Math.min(r.left - box.left, box.width - bubble.offsetWidth - 8)) + 'px';
      }
      body.addEventListener('click', e => {
        const a = e.target.closest('a');
        if (a && (e.metaKey || e.ctrlKey)) { e.preventDefault(); window.open(a.href, '_blank', 'noopener'); hideLinkBubble(); return; }
        if (a) showLinkBubble(a); else hideLinkBubble();
      });
      body.addEventListener('input', hideLinkBubble);
      body.addEventListener('scroll', hideLinkBubble);
      body.addEventListener('blur', hideLinkBubble);
      body.addEventListener('keydown', e => { if (e.key === 'Escape') hideLinkBubble(); });
```

O código usa o que já existe em renderNoteEditor: `body` (o .notes-body), `notesEditor` e `syncBody`. Se tiverem outro nome no pacote, adapte a chamada, não a decisão. Se o bloco antigo estiver um pouco diferente, substitua o equivalente (o listener de click com metaKey/ctrlKey e o mouseover que grava o title).
